# Cacti Architecture

Hyperledger Cacti is organized as a set of modules, services, and libraries that offer a selection of cross-network transaction pipelines. Applications can be constructed by picking and choosing from the collection.

## Component Overview

### Core and SDK
*   **Core Libraries:** Foundational SDK components (`common`, `core`, `core-api`) providing standardized interfaces, base classes, and utilities for all Cacti modules.
*   **API Server:** The centralized orchestration engine that manages plugins, authenticates requests, and routes transactions to the appropriate ledger connectors.
*   **API Client:** Default client library for application developers interacting with a Cacti API server.

### Ledger Connectors
Standardized bridging modules that translate Cacti instructions into ledger-specific transactions. Active connectors include Besu, Fabric, Ethereum, Corda, and Stellar.

### Protocol and Interoperability Plugins
*   **Weaver:** Relay-based interoperability framework for state proofs and secure data sharing across disjoint networks.
*   **COPM:** Cross-chain Operations and Lifecycle Management subsystem for governing cross-chain activity.
*   **SATP Hermes:** A business logic plugin implementing the Secure Asset Transfer Protocol for atomic cross-chain asset transfers.

## Architecture Map

The following component map illustrates the logical relationships between the subsystems:

```mermaid
flowchart TD
    App[Client Application]
    Core[Core Libraries]
    API[API Server]
    Hermes[SATP Hermes]
    COPM[COPM]
    Weaver[Weaver Relay]

    subgraph Connectors [Ledger Connectors]
        Besu[Besu]
        Fabric[Fabric]
        Stellar[Stellar]
    end

    App -->|Uses| Core
    App -->|Requests| API
    Hermes -->|Orchestrates via| API
    API -->|Routes to| Besu
    API -->|Routes to| Fabric
    API -->|Routes to| Stellar
    COPM -->|Monitors| API
    Weaver -->|Relays across| Connectors

    Besu -->|Connects to| DLT1[(Hyperledger Besu)]
    Fabric -->|Connects to| DLT2[(Hyperledger Fabric)]
    Stellar -->|Connects to| DLT3[(Stellar Network)]
```
