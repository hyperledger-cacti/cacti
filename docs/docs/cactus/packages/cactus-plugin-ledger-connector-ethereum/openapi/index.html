GasTransactionConfig - Up

Transaction gas settings.
gas (optional)
String A maximum amount of gas a user is willing to provide for the execution of the transaction. (gasLimit)
gasPrice (optional)
String A price (in Wei) a user is willing to pay for each unit of gas used during the execution of the transaction. In EIP-1559 (London fork) networks, it will be set as both maxFeePerGas and maxPriorityFeePerGas.
gasLimit (optional)
String A maximum amount of gas a user is willing to provide for the execution of the transaction.
maxFeePerGas (optional)
String A maximum fee (including the base fee and the tip) a user is willing to pay per unit of gas.
maxPriorityFeePerGas (optional)
String A maximum tip amount a user is willing to pay per unit of gas.
