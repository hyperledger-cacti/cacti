# Supported Ledgers

Hyperledger Cacti integrates with supported distributed ledgers through
dedicated connector packages. Each connector README contains installation,
configuration, API, usage, and validation guidance.

| R3 Corda | [`@hyperledger-cacti/cactus-plugin-ledger-connector-corda`](https://github.com/hyperledger-cacti/cacti/tree/main/packages/cactus-plugin-ledger-connector-corda) |
| Stellar | [`@hyperledger-cacti/cacti-plugin-ledger-connector-stellar`](https://github.com/hyperledger-cacti/cacti/tree/main/packages/cacti-plugin-ledger-connector-stellar) |
