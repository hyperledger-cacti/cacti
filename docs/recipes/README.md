# Technical Recipes

Self-contained, task-oriented guides for common Cacti development workflows.
Each recipe can be followed independently — pick the one that matches what
you need to do.

> expectations, and governance rules.

## Recipe Template

All recipes follow a consistent structure:

1. **Prerequisites** — what you need before starting
2. **Steps** — numbered step-by-step instructions
3. **Expected Outcome** — what success looks like
4. **Related** — links to other docs and recipes
